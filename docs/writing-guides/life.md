# life 카테고리 글쓰기 가이드

[common.md](./common.md)를 먼저 적용하고, 아래 규칙을 더한다.

## 성격

생활 정보·습관·계절 대응 글. 현재 전량 `draft`이며 **AdSense 승인 전 발행 금지**.
승인 후에도 아래 조건을 충족한 글만 단계적으로 발행한다.

## 제품 리뷰 글 (쿠팡 파트너스 포함) — 특별 규칙

Google 제품 리뷰 정책과 AdSense 저가치 콘텐츠 판정의 최대 위험 지대다.

- **실사용 증거 없는 리뷰 발행 금지.** 직접 촬영한 사진, 실제 사용 기간, 장단점 실측 경험이 본문에 있어야 한다. 판매 페이지 이미지만 있는 리뷰는 draft 유지.
- 제휴 링크가 있는 글은 대가성 문구를 본문 상단에 명시한다.
- 제휴 관련 태그·단어(쿠팡, 파트너스, 제휴, 상품, 추천, 제품리뷰 등)는 AdSense 격리 시스템(`src/lib/posts.ts`)이 자동으로 광고 노출에서 제외한다. 이 격리를 우회하도록 태그를 바꾸지 말 것.
- 장점만 나열 금지. 실제 단점·어떤 사람에게 안 맞는지 반드시 포함.

## 정보성 생활 글

- 근거 있는 내용만: 공공기관 자료, 제조사 공식 안내, 검증 가능한 생활 상식.
- 건강 관련 내용은 의학적 단정 금지. "일반적으로 알려진 수준 + 전문가 상담 안내" 프레임 유지.
- 저자 페르소나와의 접점: 재택근무하는 개발자의 생활 관점이 자연스럽다. 억지로 기술 얘기를 넣지는 말 것.

## 분량·구성

- 본문 4,000자 이상. 체크리스트·표 활용 권장.
- 도입은 계절·상황 공감에서 시작하되, 문형은 글마다 다르게.
