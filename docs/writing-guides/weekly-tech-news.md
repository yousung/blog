# 주간 테크 뉴스 시리즈 가이드

[common.md](./common.md)를 먼저 적용. engineering 카테고리 소속이지만 시리즈 전용 형식을 따른다.
기본 뼈대는 `docs/templates/weekly-tech-news-post.md` 템플릿 참고.

## 성격

매주 월요일 발행하는 큐레이션 시리즈. **시리즈는 고정 포맷이 정상이다** — 구조를 매번 바꾸지 말 것. common.md의 구조 다양화 규칙 중 "글마다 구조를 다르게" 항목은 이 시리즈에 적용하지 않는다.

## 고정 형식

- slug: `weekly-tech-news-YYYY-MM-DD` (해당 주 시작일)
- 요약 라벨: **"이번 주 요약"** (시리즈 고유 라벨, 유지)
- 뉴스 항목 구조: 사실 서술 → 출처 링크 → 운영자 코멘트

## 다양화할 것 (고정 형식 안에서)

- 도입 문단: 매주 같은 문형으로 시작 금지. 그 주 최대 뉴스로 바로 들어가기 / 소회로 시작 / 흐름 요약으로 시작 등 로테이션.
- frontmatter `summary` 어미: 직전 회차들과 겹치지 않게.

## 운영자 코멘트 규칙

- 각 뉴스에 중소기업 CTO 시각의 판단 1~3문장: "우리 팀 규모라면", "당장 도입하나 관망하나", "실무 영향은 어디에".
- 뉴스 사실과 코멘트를 명확히 분리. 사실은 출처 그대로, 판단은 1인칭으로.
- 뉴스 사실·제품명·발표 내용·링크는 절대 변형·과장하지 않는다.

## 소재 기준

- 개발자 도구·플랫폼·AI·클라우드 분야. 발표일이 해당 주에 속하는 것만.
- 출처는 공식 블로그·공식 문서·신뢰 가능한 1차 보도만.
