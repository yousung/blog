## 마이크로소프트 Edge란?

[마이크로소프트 Edge](https://www.microsoft.com/ko-kr/windows/microsoft-edge)는 Windows에 기본으로 탑재되는 브라우저입니다.

출시 당시 터치 인터페이스와 펜 입력을 지원하여 당시 함께 출시된 Surface와의 시너지를 기대했습니다. 하지만 예상과 달리 자사의 IE에도 밀려나면서 존재 자체를 모르는 사람이 있을 정도로 불운한 브라우저였습니다.

실제로 사용하면 깔끔한 UI/UX를 제공하고 있지만, 애매한 포지셔닝이 문제였습니다:
- **IE 사용자**: 호환성 때문에 IE 사용
- **Chrome/Firefox 사용자**: 매력 부족으로 전환 거절

## IE의 악재

개발자라면 한 번쯤 들어본 **React**와 **Vue**는 차기 버전부터 IE 지원을 종료합니다. 

미국은 IE에 대해 자비가 없는 것 같습니다. 한국은 아직도 IE 사용자가 많지만 전 세계적으로는 IE 점유율이 빠르게 떨어지고 있습니다. 그렇다면 Microsoft에게 남은 브라우저는 어떻게 될까요?

## 최후의 선택: Chromium으로의 전환

2018년 12월 6일, Microsoft는 공식 블로그를 통해 Edge의 렌더링 엔진을 Chromium으로 변경하기로 발표했습니다.

> "For the past few years, Microsoft has meaningfully increased participation in the open source software (OSS) community, becoming one of the world's largest supporters of OSS projects. Today we're announcing that we intend to adopt the **Chromium open source project** in the development of Microsoft Edge on the desktop to create better web compatibility for our customers and less fragmentation of the web for all web developers."

[Window Blog 인용](https://blogs.windows.com/windowsexperience/2018/12/06/microsoft-edge-making-the-web-better-through-more-open-source-collaboration/)

Chromium은 오픈소스로 개발 중인 브라우저 엔진으로, 주요 브라우저로는 Chrome, Opera, Vivaldi 등이 있습니다.

## Chromium 전환의 영향

### 개발자에게 긍정적인 영향

오픈소스의 확장성은 누구나 알 수 있습니다. Apple의 iPhone이 한때 앱 시장을 주도했으나 오픈소스 Android에 밀리고 있으며, 오픈소스에 참여하는 개발자가 많을수록 개발 속도와 편의 기능이 빠르게 발전합니다.

**최악의 크로스 브라우징 문제였던 MS가 Google Chrome과 동일한 수준으로 변경될 것으로 예상됩니다.** 이는 개발자들의 극심한 피로가 해소되는 것이며, 더 빠른 개발이 가능해집니다.

### 멀티 플랫폼 지원

지금까지 고집해온 EdgeHTML은 Windows에서만 작동했습니다. 하지만 Chromium을 사용하면 운영체제의 영향을 덜 받아 Windows뿐만 아니라 Linux, Mac 등에서도 Edge가 나타날 가능성이 높습니다.

## Chrome과 Firefox를 대체할 수 있을까?

한국의 ActiveX 환경에서 IE는 여전히 필요합니다. 하지만 Edge가 Chromium으로 전환된다면 Chrome과 Firefox 같은 브라우저들과 경쟁해야 합니다.

Chromium이 만능 열쇠는 아닙니다. 한국의 Naver에서 만든 [Whale 브라우저](https://whale.naver.com/ko/)도 Chromium을 기반으로 하지만, 한국형 특화 편의 기능을 제공함에도 불구하고 존재조차 모르는 사람이 많습니다.

그러나 기본으로 깔려있는 Edge가 Chrome과 비슷한 수준의 성능을 제공한다면? 소비자의 선택이 어떻게 될지 변수가 너무 많습니다.

## 우려: 다양성과 독점

### Chromium 점유율의 확대

Chromium 브라우저는 이제 Google Chrome, Opera, MS Edge, (Naver Whale) 등 더 많은 브라우저가 생겨났습니다.

### 독점에 대한 우려

하지만 Chromium 기반 브라우저의 증가가 다양성을 보장하는가라는 의문이 있습니다. 실제로 MS Edge의 실사용자가 얼마나 있었을까요?

**통계의 어려움**: 사용자 기반이 너무 적어서 IE와 통합해서 통계를 내는 경우가 많습니다.

### 실제 데이터 분석

필자가 서비스하는 사이트 접속자 통계(IE 사용자가 많은 특성)를 보면:
- 대부분이 모바일 통합 통계
- 기타 항목에 Firefox, IE, Edge가 합쳐짐
- Edge 사용자는 겨우 1~2명 수준

**결론**: IE 사용자 비율은 매우 높고 기본 브라우저를 사용한다는 뜻입니다. 많은 사람들이 우려하는 다양성과 독점 문제를 제기하기에는 Edge의 실사용자가 너무 적었습니다.

(사실 IE CSS 맞추는 게 더 큰 스트레스... )

## 마치며

Microsoft의 Edge Chromium 전환은 IE 종료의 흐름 속에서 자신의 위치를 재정의하려는 전략입니다. 이 변화가 웹 개발 생태계에 미칠 영향은 긍정적일 것으로 예상되지만, 브라우저 다양성 문제는 앞으로도 주의 깊게 살펴봐야 할 주제입니다.
