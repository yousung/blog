## 개요

스마트폰이나 카메라로 찍은 사진 중에는 날짜가 잘못되거나 GPS 위치가 기록되지 않은 것들이 있습니다. 특히 여행에서 수십 장, 수백 장을 촬영했다면 이를 일일이 수정하기는 불가능합니다. **ExifTool**은 이런 상황에서 필수적인 명령줄 도구로, EXIF 메타데이터를 한 번에 일괄 수정할 수 있습니다. 이 글은 ExifTool의 자주 사용되는 명령어를 실무 관점에서 정리했습니다.

## ExifTool 설치

```bash
brew install exiftool
```

## 사용 명령어

### 위치만 변경

```bash
exiftool -gpslatitude=37.6534 -gpslongitude=126.8321 -gpslatituderef=N -gpslongituderef=E -overwrite_original /경로/사진_폴더/*.jpg
```

### 날짜만 변경

```bash
exiftool "-AllDates=2024:08:24 12:34:56" -overwrite_original /경로/사진_폴더/*.jpg
```

### 날짜와 위치 모두 변경

```bash
exiftool "-AllDates=2024:08:24 12:34:56" -gpslatitude=37.5665 -gpslongitude=126.9780 -gpslatituderef=N -gpslongituderef=E -overwrite_original /경로/사진_폴더/*.jpg
```

## 매개변수 설명

- `-gpslatitude` : 위도 값 (숫자)
- `-gpslongitude` : 경도 값 (숫자)
- `-gpslatituderef` : 위도 기준 (N=북위, S=남위)
- `-gpslongituderef` : 경도 기준 (E=동경, W=서경)
- `-AllDates` : 모든 날짜 관련 EXIF 필드 변경
- `-overwrite_original` : 원본 파일을 직접 수정

## 한국 좌표 예시

- **서울**: 위도 37.5665, 경도 126.9780
- **부산**: 위도 35.1796, 경도 129.0756

## 주의사항

- `-overwrite_original` 플래그를 사용하면 원본 파일이 직접 수정됩니다. 백업을 먼저 해두는 것이 안전합니다.
- 사진 폴더 경로는 정확하게 입력해야 합니다.
- 날짜 형식은 `YYYY:MM:DD HH:MM:SS` 형식을 따릅니다.

## 결론

ExifTool은 강력한 EXIF 메타데이터 관리 도구입니다. 대량의 사진을 정리하거나 GPS 위치가 잘못된 사진을 수정할 때 매우 유용합니다.
