## 먼저 볼 구매 기준

React 책은 입문 난도, TypeScript 포함 여부, Next.js 버전, 예제 실행 환경을 먼저 확인해야 합니다. HTML과 JavaScript 기초가 약한 상태라면 실전 웹앱 책이 빠르게 느껴질 수 있고, 반대로 이미 React를 써본 사람이라면 단순 문법 입문서가 부족하게 느껴질 수 있습니다.

Next.js는 버전 변화가 빠른 편이라 책의 설명과 현재 공식 문서가 다를 가능성도 봐야 합니다. 한 권으로 전체 흐름을 잡되, 예제 실행 중 막히는 부분은 공식 문서와 함께 확인할 수 있는 독자에게 더 잘 맞습니다.

## 책상에 올렸을 때 먼저 보이는 부분

이 책은 React만 단독으로 보는 책이라기보다 TypeScript와 Next.js를 함께 다루는 현대 웹 애플리케이션 개발서에 가깝습니다. 이미 JavaScript 기본을 알고 있고 실전 앱 구조를 보고 싶은 사람에게 더 잘 맞습니다.

백엔드 개발자가 프론트엔드로 확장할 때는 React 컴포넌트 문법뿐 아니라 라우팅, 데이터 패칭, 타입 설계, 배포 구조까지 같이 봐야 합니다.


## 생활에서 먼저 체감될 장점

책 소개를 보면 TypeScript, React, Next.js를 함께 다룬다는 점이 가장 큰 장점입니다. 지금 실무에서 자주 만나는 조합을 한 권에서 연결해 볼 수 있습니다.

## 아쉬운 점과 주의할 점

프론트엔드가 완전 처음이라면 난도가 높게 느껴질 수 있습니다. JavaScript 기본 문법, npm, 브라우저 동작 방식을 모르면 책의 흐름을 따라가다 막힐 수 있습니다.

Next.js는 버전 변화가 빠르므로 책의 예제와 현재 공식 문서가 다를 수 있습니다. 구매 전 출간 시점과 사용하는 Next.js 버전을 확인해야 합니다.
