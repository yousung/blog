## 근황 및 필자의 공부법

![react 이미지](/images/posts/react/img-01.jpg)

필자는 백엔드(BE) 개발자다. 다만 최근에는 프론트엔드(FE) 개발에 관심을 많이 갖고 있다. 이 변화에 대해서는 별도의 포스팅으로 다룰 예정이다.

지금까지 Angular, Vue, React 등 다양한 프런트엔드 프레임워크를 경험해봤다. 결국 **React가 최고의 선택**이라는 결론에 도달했고, 현재 React에 집중 투자하고 있다.

### 개인적인 공부 방법론

사람마다 공부 방법은 다르다:

- **타입 A**: 예제만 따라 쳐도 학습이 된다
- **타입 B**: 이론을 먼저 이해하고 실습하는 방식을 선호한다

필자는 **타입 B**에 속한다.

따라서 필자의 학습 방법은:
1. 책으로 이론 이해
2. Udemy 강의로 예제 실습

이 방식으로 월 2~30만 원을 책과 온라인 강의에 투자하고 있다 (개인 비용. 회사에서 책을 지원해주니 정말 감사하다!)

### Vue vs React 학습 자료

**Vue**: 공식 문서가 매우 잘 되어있어서 굳이 책을 살 필요가 없다. 시중의 책들은 대부분 문서를 잘 정리한 수준이다.

**Angular**: 이건... (한숨)

**React**: 너무 많고 너무 다양하다. 이것이 바로 우리의 도전 과제다.

## React 책 선택의 어려움

한국 시장에는 React 책이 정말 많다:

- 벨로퍼트님의 책 (React 선구자)
- 대기업 CTO의 책
- 다양한 개발자들의 책

당연히 최신 책이 최신 기술을 많이 담고 있어서 좋겠지만, 꼭 그렇지만은 않다.

### 추천하는 책: 실전 React 프로그래밍 (이재승 저자)

필자가 추천하는 책은 **"실전 React 프로그래밍"** (저자: 이재승)이다.

**추천 이유**:

1. **균형잡힌 내용**: 다른 책들은 예제가 과다하거나 실무 기술이 부족한 경향이 있다. 이 책은 그 균형이 좋다.

2. **최신 기술 포함**: 
   - Next.js
   - Hook
   - 최신 패턴과 기법

3. **벨로퍼트님 책의 한계 극복**: 벨로퍼트님의 책은 훌륭하지만 출판된 지 시간이 경과했다. 특히 불필요한 부분(예: Koa 프레임워크)이 많이 있고, 입문자에게는 과도할 수 있다.

4. **실무 집중**: 진정으로 필요한 기술들만 선별해서 담았다. 불필요한 것 없이 깔끔하다.

5. **방향 제시**: 책의 마무리에서 다음에는 무엇을 배워야 할지 방향을 제시해준다. 이것이 매우 가치 있다.

## 책 선택의 관점

이것은 개인적인 견해임을 인정한다. 사람마다 다를 수 있다:

- **이론 중심을 원하는 경우**: 다른 책이 더 좋을 수 있다
- **그냥 직접 만들고 싶은 경우**: 예제 중심 책이 더 적합하다
- **실무에 바로 적용하고 싶은 경우**: 이 책을 강력 추천한다
