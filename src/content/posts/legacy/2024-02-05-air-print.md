## 도입: Linux 프린터를 Apple 기기와 연결하기

많은 Linux 사용자가 집이나 사무실의 일반 프린터를 **iPhone이나 iPad에서 바로 사용하고 싶어** 합니다. 별도의 드라이버를 설치하거나 복잡한 설정 없이 말이죠. **CUPS (Common Unix Printing System)**를 사용하면 이것이 가능합니다. 

CUPS는 Linux의 표준 인쇄 시스템으로, Apple의 **AirPrint 프로토콜**을 지원하여 iPhone, iPad, Mac에서 바로 인쇄할 수 있게 합니다.

## CUPS 설치 및 기본 설정

### 1단계: CUPS 패키지 설치

먼저 시스템에 CUPS를 설치합니다. Ubuntu/Debian 기준입니다:

```bash
# CUPS 설치
sudo apt update
sudo apt install cups

# CUPS 서비스 시작
sudo systemctl start cups
sudo systemctl enable cups
```

### 2단계: CUPS 웹 인터페이스 접근

브라우저를 열고 다음 주소로 접속합니다:

```
http://localhost:631
```

또는 네트워크 상의 다른 컴퓨터에서 접근하는 경우:

```
http://<Linux-서버-IP>:631
```

CUPS 웹 인터페이스가 열리면, **Administration** 탭에서 프린터를 관리할 수 있습니다.

### 3단계: 관리자 권한 설정

프린터를 추가하고 설정하려면 **관리자 권한**이 필요합니다. 현재 Linux 사용자를 CUPS 관리 그룹에 추가하세요:

```bash
# 사용자를 lpadmin 그룹에 추가
sudo usermod -aG lpadmin $USER

# 변경사항 적용 (로그아웃 후 다시 로그인 또는)
newgrp lpadmin
```

## 프린터 추가 및 공유 설정

### 1. CUPS 관리 페이지에서 프린터 추가

1. `http://localhost:631/admin` 접속
2. **Manage Printers** → **Add Printer** 클릭
3. USB 또는 네트워크 프린터 선택
4. 프린터 이름 및 설명 입력
5. **Share This Printer** 체크박스 선택
6. **Continue** → **Set Printer Options** → **Set Default Options**

### 2. CUPS 설정 파일 수정

프린터 공유를 위해 설정 파일을 편집해야 할 수 있습니다:

```bash
sudo nano /etc/cups/cupsd.conf
```

다음 섹션을 찾아서 수정하세요:

```conf
# 외부 접근 허용 (모든 네트워크)
<Location />
  Order allow,deny
  Allow all
</Location>

<Location /admin>
  Order allow,deny
  Allow all
</Location>

<Location /admin/conf>
  Order allow,deny
  Allow all
</Location>
```

수정 후 CUPS를 재시작합니다:

```bash
sudo systemctl restart cups
```

## AirPrint 자동 발견 설정

CUPS는 기본적으로 AirPrint를 지원하지만, 몇 가지 추가 패키지가 필요할 수 있습니다:

```bash
# avahi (mDNS) 설치 - AirPrint 발견에 필수
sudo apt install avahi-daemon

# avahi 서비스 시작
sudo systemctl start avahi-daemon
sudo systemctl enable avahi-daemon
```

이제 Apple 기기에서 **Settings > Printers & Scanners**에 가면 네트워크의 CUPS 프린터가 **자동으로 발견**됩니다.

## 트러블슈팅

### 프린터가 발견되지 않는 경우

```bash
# CUPS 상태 확인
sudo systemctl status cups

# avahi 상태 확인
sudo systemctl status avahi-daemon

# CUPS 로그 확인
sudo tail -f /var/log/cups/error_log
```

### 프린터는 보이지만 인쇄 안 되는 경우

```bash
# 프린터 상태 확인
lpstat -p -d

# 프린터 테스트
lp -h localhost /etc/hostname
```

### 권한 문제

```bash
# cups 그룹 확인
groups $USER

# 다시 로그인해야 변경사항 적용됨
```

## 마치며

CUPS와 AirPrint는 Linux에서 프린터를 최대한 간편하게 공유할 수 있는 훌륭한 조합입니다. 한 번 설정하면:

✅ 드라이버 설치 없이 Apple 기기에서 자동 발견  
✅ iPhone, iPad, Mac에서 모든 앱에서 인쇄 가능  
✅ 네트워크 프린터처럼 사용 가능  
✅ 별도의 인쇄 소프트웨어 불필요

초기 설정 이후로는 더 이상 번거로운 작업이 필요하지 않습니다. 네트워크에 연결된 모든 Apple 기기에서 **자동으로 프린터를 찾아 인쇄**할 수 있습니다.
