## Intel 맥북에서 Apple Silicon으로의 전환기

2020년부터 사용해온 Intel 맥북 Pro는 충분히 좋은 기기였습니다. 하지만 Apple이 M1을 출시하면서 업계의 패러다임이 변했습니다. M1을 체험한 후로는 Intel 기반 Mac으로 돌아갈 수 없게 되었습니다. 결국 이번 M2 Pro 업그레이드를 결정하게 되었습니다.

## 업그레이드 결정의 주된 이유

### SSD 용량 부족의 악순환

원래 M1 Air를 사용하고 있었는데, 구매 당시 RAM만 업그레이드하고 SSD는 256GB로 선택했습니다. 이것이 최대의 실수였습니다.

웹 개발, Flutter 앱 개발, 사진/영상 작업을 병행하면서 256GB는 금세 가득 찼습니다. Node.js 프로젝트의 node_modules, Docker 이미지, 개발 도구들이 디스크를 점령하면서:

- 매주 불필요한 파일을 정리해야 했습니다
- 설치했던 프로그램을 지웠다 깔았다를 반복했습니다
- 시스템이 느려지면서 업무 효율이 떨어졌습니다

M2 Pro로 업그레이드하면서 SSD를 512GB로 증설함으로써 이 악순환을 깨뜨렸습니다.

## 실제 업그레이드 후 성능 변화

### Apple Silicon의 성숙한 생태계

![M2 MacBook 성능 화면](/images/posts/m2-feat/img-01.png)

M1 초기에는 많은 앱이 Rosetta 에뮬레이션으로 실행되었습니다. 지금은 대부분의 주요 애플리케이션이 Apple Silicon 네이티브를 지원합니다. (2023년 4월 기준으로 KakaoTalk도 정식 지원 시작)

### 실무에서의 체감 성능

풀스택 개발자로서 주로 다음 작업들을 수행합니다:
- PHP 백엔드 개발
- Node.js 서버 개발
- Flutter 모바일 앱 개발
- Docker 컨테이너 관리

**M2 Pro의 성능은 매우 쾌적합니다.**

흥미롭게도, Docker 작업이나 StableDiffusion으로 이미지를 생성할 때를 제외하고는 팬이 거의 도는 일이 없습니다. 일반적인 웹 개발 작업에서는 무음에 가까운 수준으로 동작합니다.

### M2만의 고유한 이점: 멀티 모니터 지원

M1 Pro (13인치)와 M2 Pro의 가장 큰 차이 중 하나는 외부 모니터 지원입니다.

**M1 Pro의 제약:**
- 기본적으로 외부 모니터 1개만 지원
- 2개를 쓰려면 DisplayLink 어댑터 필수
- DisplayLink 사용 시 CPU 점유율이 상당함

**M2 Pro의 개선:**
- 기본적으로 외부 듀얼 모니터 지원
- CPU 점유율 최소화
- 멀티모니터 작업이 더 부드러움

이 차이는 생각보다 큽니다. 개발 시 메인 코드, IDE, 문서를 동시에 표시할 수 있으면 생산성이 크게 향상됩니다.

## M2 Pro를 추천하는 경우

1. **Intel 맥북 사용자**: Apple Silicon으로 완전히 전환할 가치가 충분합니다
2. **외부 모니터 2개 필요한 개발자**: M2 Pro의 멀티모니터 네이티브 지원이 큰 이점
3. **리소스 집약적 작업**: Docker, 컨테이너, 가상머신 작업이 많다면 M2의 성능 향상을 체감할 수 있습니다

## M2 Pro를 추천하지 않는 경우

1. **현재 맥북이 충분한 경우**: M1 Air도 대부분의 개발 작업에 충분합니다. 고집적인 작업을 하지 않는다면 업그레이드 효과가 크지 않을 수 있습니다
2. **M1 13인치 사용자**: 외부 모니터 1개만 사용한다면 성능 차이를 크게 느끼지 못할 수 있습니다

## 인텔 사용자에게 전하는 조언

Intel 맥북을 여전히 사용 중이라면 **꼭 Apple Silicon으로 전환하세요.** M2가 부담된다면 M1 Pro라도 충분합니다. 로제타 에뮬레이션의 성능 저하도 사실상 문제가 되지 않을 정도로 생태계가 성숙했습니다.

## 결론

M2 Pro 업그레이드는 단순한 성능 향상을 넘어, 개발 환경의 질적 변화를 가져왔습니다. 특히 멀티모니터 지원과 안정적인 애플리케이션 생태계는 일상적인 개발 작업의 효율성을 크게 높여줍니다.

SSD 용량 부족으로 고민하던 시절은 이제 완전히 사라졌고, 마음 놓고 다양한 개발 도구와 프로젝트를 동시에 관리할 수 있게 되었습니다.
